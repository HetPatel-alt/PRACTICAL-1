StudentHub — Practical 3: Responsive UI Design

Implemented from the Practical 3 problem definition:
- Home, About, Registration, Dashboard, and Events pages.
- CSS Grid and Flexbox layouts.
- Media queries for responsive mobile, tablet, and desktop layouts.
- Consistent typography, spacing, colors, and readable contrast.
- One shared CSS stylesheet.

No Bootstrap, Tailwind, JavaScript, Contact page, or Feedback page has been added because these are optional or extension items rather than part of the stated core problem definition.

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Resize the browser or use responsive mode to inspect mobile, tablet, and desktop layouts.

Note: Registration is a static UI form. No backend or data storage is included.
