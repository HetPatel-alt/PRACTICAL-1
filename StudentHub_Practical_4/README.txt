StudentHub Practical 4 — Multi-page Version

Pages:
- index.html — Home and notification banner
- about.html — About page and collapsible FAQ
- register.html — Registration form with client-side demo feedback
- dashboard.html — Dashboard cards and modal popup
- events.html — Event slider
- css/style.css — Shared responsive styling and transitions
- js/script.js — Shared JavaScript for menu, theme, FAQ, notification, modal, slider, and form demo

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Use the navigation to open each separate page.
4. Test the theme switcher and refresh a page to confirm the preference persists.
5. Try the FAQ, notification, modal, event slider, and registration form.

Uses HTML5, CSS3, and vanilla JavaScript only. No framework, backend, or database is included.
