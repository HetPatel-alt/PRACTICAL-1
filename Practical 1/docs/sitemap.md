```text
├── Events (events.html)
├── Feedback (feedback.html)
├── FAQ (faq.html)
├── Contact (contact.html)
├── Login (login.html)
├── Register (register.html)
└── Admin overview (admin.html)
```

## Main navigation flow
- Public visitor: Home → About / Events / FAQ / Contact
- New student: Home → Register → Login → Dashboard → Profile
- Returning student: Home → Login → Dashboard → Events / Feedback / Profile
- Administrator: Login → Admin overview (future role-protected flow)

In this Practical 1 prototype, the pages are static and the navigation demonstrates the intended information architecture. Authentication and access restrictions will be implemented in later practicals.
