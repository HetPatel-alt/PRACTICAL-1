# StudentHub — Practical 1

## Project overview
StudentHub is a planned university student portal that brings common student information and campus activities into one place. This Practical 1 folder includes the initial project structure, requirement analysis, sitemap, wireframe notes, and a static HTML/CSS project foundation based on the supplied wireframes.

## Pages planned
1. Home (`index.html`)
2. About (`about.html`)
3. Dashboard (`dashboard.html`)
4. Events (`events.html`)
5. Feedback (`feedback.html`)
6. FAQ (`faq.html`)
7. Login (`login.html`)
8. Register (`register.html`)
9. Contact (`contact.html`)
10. Profile (`profile.html`)
11. Admin overview (`admin.html`)

The login, registration, feedback, and admin views are demonstration front-end pages only. Authentication, data storage, permissions, and database operations are not implemented in Practical 1.

## Run the project
1. Extract the ZIP file.
2. Open the `Practical 1` folder.
3. Double-click `index.html` to open it in a browser, or open the folder in VS Code and use the Live Server extension.
4. Use the navigation links to visit the other pages.

No package installation or server is required for this static version.

## Accessibility and responsive design
- Semantic HTML landmarks and a skip-to-content link are included.
- Navigation has an accessible mobile menu button.
- Form fields have labels, and messages use `aria-live`.
- Layouts adapt to smaller screens using CSS media queries.
- Keyboard focus and reduced-motion preferences are supported.
